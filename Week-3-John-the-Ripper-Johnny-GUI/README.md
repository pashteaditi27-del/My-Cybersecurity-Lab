# Week 3: Password Cracking Using John the Ripper & Johnny GUI

## 1. Introduction

This practical focuses on understanding password security and password recovery using John the Ripper and Johnny GUI.

The objective was to learn how password hashes can be tested against password guesses and understand the importance of strong passwords.

## 2. Objectives

- Install John the Ripper on Windows.
- Install and configure Johnny GUI.
- Understand password hashing.
- Load a password hash from a text file.
- Perform password recovery on an authorized test file.
- Understand the importance of password complexity.

## 3. Tools Used

| Tool | Purpose |
|---|---|
| John the Ripper | Password auditing and recovery |
| Johnny GUI | Graphical interface for John the Ripper |
| Windows | Operating system used for the practical |
| Notepad | Creating and saving the hash text file |
