# Week 1: Wireshark Project

## Project Overview
Completed five practical Wireshark labs as part of my Cybersecurity Internship at NetworkWalks.

## Labs Completed

1. **Follow TCP Stream**  
   Used Follow TCP Stream to investigate captured web traffic and identify hidden information.

2. **Catch the Call Scammer**  
   Investigated VoIP traffic and replayed a captured call.

3. **HTTP Plain Text Credentials**  
   Analyzed HTTP traffic to understand how credentials can be exposed in plain text.

4. **Capture Packets on Your Network and PC**  
   Practiced capturing network traffic and identifying IP addresses, DNS servers, server names, ports and TLS versions.

5. **Analyze a PCAP File**  
   Analyzed a saved network capture of microsoft.com.

## Tools Used
- Wireshark
- Network packet capture files (PCAP)

## Skills Practiced
- Network Traffic Analysis
- Follow TCP Stream
- VoIP Traffic Investigation
- HTTP Traffic Analysis
- Packet Capture
- PCAP Analysis
- DNS and TLS Identification

## Conclusion
These practical labs helped me develop foundational skills in network traffic analysis and understand how Wireshark is used in cybersecurity and SOC investigations.
