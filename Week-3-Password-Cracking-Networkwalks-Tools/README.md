# Week 3: Password Cracking with Networkwalks Tools

## 1. Introduction

This practical focuses on understanding password cracking and password security using Networkwalks online tools.

The objective was to extract a password hash from an authorized password-protected PDF and use the Networkwalks Password Cracker to recover its password.

## 2. Objectives

- Understand password hashing and encryption.
- Extract a PDF password hash.
- Use the Networkwalks Hash Calculator.
- Use the Networkwalks Password Cracker.
- Understand password recovery techniques.
- Learn why strong passwords are important.

## 3. Tools Used

| Tool | Purpose |
|---|---|
| Networkwalks Hash Calculator | Extracting the PDF password hash |
| Networkwalks Password Cracker | Testing password guesses against the hash |
| Web Browser | Accessing the online tools |
| Windows | Operating system used for the practical |

## 4. Activities Performed

### 4.1 Downloading the Test PDF

Downloaded the authorized password-protected PDF file named `My Locked PDF1.pdf` from the lab resources.

### 4.2 Extracting the PDF Hash

Opened the Networkwalks Hash Calculator and uploaded the test PDF to obtain its password hash.

### 4.3 Copying the Hash

Copied the complete hash value beginning with `$pdf$`.

### 4.4 Password Recovery

Opened the Networkwalks Password Cracker, pasted the extracted hash, and started the password recovery process.

### 4.5 Verifying the Recovered Password

After the tool completed the recovery process, used the recovered password to open the authorized test PDF.

## 5. Key Learnings

- Understanding the difference between hashing and encryption.
- Learning how password hashes are extracted from protected PDF files.
- Understanding the basic password recovery workflow.
- Learning how password complexity affects recovery time.
- Recognizing the importance of strong password protection.

## 6. Security Recommendations

- Use long and complex passwords.
- Avoid common and predictable passwords.
- Never reuse passwords across multiple accounts.
- Use a trusted password manager.
- Protect confidential documents with strong passwords.
- Perform password testing only with proper authorization.

## 7. Conclusion

This practical provided hands-on experience with the Networkwalks Hash Calculator and Password Cracker. It helped develop a basic understanding of PDF password hash extraction, password recovery, and the importance of strong passwords.
